# ADR-0002 — Repositorio fuente como referencia inmutable

- Estado: Aceptado
- Fecha: 2026-09-25

`Electroingenieria-SAS/CRM-SUMINISTROS` no se usa como laboratorio de la reconstrucción. La migración parte del commit `4bdceeaa54847581f83e9425aa0310aae8b0547d` y cualquier cambio posterior del producto fuente se evalúa mediante una actualización explícita de la matriz de paridad.
